# 开发者文档

> 面向**维护者与贡献者**：架构分层、构建流程、能力边界的技术分析。
> 面向用户的说明在仓库根目录的 `README.md`。

## 为什么用户文档与开发文档分开

1. **用户看到开发流程会困惑** —— `pip install -e ".[dev]"`、`cargo test`、
   托盘图标离线渲染验证……这些对普通用户毫无意义，只会让人以为要自己编译。
2. **文档必须随码走** —— 架构文档不跟着代码入库，clone 下来的人就只能靠猜；
   而过期文档比没有文档更糟（会把人引向已经不存在的模块）。
