## 一、项目概述

### 1.1 产品定位

道体·玄盾是一套面向大语言模型（LLM）的**运行时安全防火墙**，在用户输入到达模型前和模型输出返回用户前进行双向安全检测，拦截 Prompt Injection、敏感信息泄露、输出操纵等攻击。

### 1.2 核心理念

- **活性防护**: 不依赖硬编码黑名单，通过多维符号空间映射 + 动态变换 + 时序一致性实现语言无关的攻击检测
- **双向闭环**: 输入侧防护（protect）+ 输出侧护栏（check_output），形成完整防御链
- **开箱即用**: 无需预训练，内置攻击原型库 + 在线自适应学习

### 4.2 主集成类 XuanDun

**文件**: [src/daoti_xuandun/xuandun.py](file:///h:/XuanDun/src/daoti_xuandun/xuandun.py)

主集成类是整个检测系统的入口编排器，串联 5 大核心模块 + 3 个附加检测器。

**初始化参数**:
- `config`: XuanDunConfig 配置对象（与 mode 互斥）
- `mode`: 简化模式（`high_security` / `balanced` / `low_false_positive`）
- `auto_warmup`: 是否自动在线学习（默认 True）
- `**config_overrides`: 在 mode 基础上微调个别配置项

**模式映射**:

| 模式 | 防御层级 | 性能开销 | 适用场景 |
|------|---------|---------|---------|
| `high_security` | STRICT | ~12% | 面向公网的高价值服务 |
| `balanced` | STANDARD | ~5% | 通用 API 网关（默认） |
| `low_false_positive` | BASIC | ~0% | 低延迟内部服务 |

另有 `PARANOID` 层级（~25% 开销），适合金融/国防场景。

**核心方法**:

| 方法 | 用途 |
|------|------|
| `protect(text)` | 输入侧检测流水线，8 阶段串行处理 |
| `check_output(text)` | 输出护栏检测，返回 allowed/risk_level/action |
| `resolve_output(text, decision)` | 输出处置决策（拦截/打码/告警） |
| `switch_mode(mode)` | 运行时模式切换 |
| `set_emergency_bypass(ratio)` | 紧急逃生通道 |
| `set_gray_deploy_ratio(ratio)` | 灰度部署 |
| `get_dual_layer_stats()` | 双层统计（输入侧+输出侧） |
| `rate_limit_status()` | 限流状态查询 |

### 4.3 检测流水线（protect 方法 8 阶段）

```
输入文本
  │
  ▼
阶段0: 前置守卫
  ├── 速率限制检查 (_check_rate_limit)
  ├── 请求长度检查 (_check_request_length)
  ├── 会话配额检查 (_check_session_quota)
  └── 熵守卫 (entropy_guard)
  │
  ▼
阶段1: 内生域感知 (domain_awareness.process)
  ├── 原型距离计算（余弦距离）
  ├── 结构异常分数（字节流/字符分布统计偏差）
  ├── 双信号融合决策 → REJECT 直接返回
  ├── 5维攻击否定信号检测
  └── 时序推进 (timing_checker.advance_turn + update_drift)
  │
  ▼
阶段2: 动态阴阳壳变换 (dynamic_shell.transform)
  ├── logistic map 混沌序列生成
  ├── 密钥+调用计数+会话种子派生偏置
  ├── 周期性随机扰动防拟合
  ├── byte_anomaly 注入
  └── 状态依赖权重演化（外积更新）
  │      │
  │      ▼ (如启用 PyO3)
  │  双梯形镜像递归网络 (Rust)
  │  ├── 正向传播：底层→顶层，捕捉结构依赖和指令嵌套
  │  ├── 逆向传播：顶层→底层，回溯语义，发现意图偏移
  │  └── 递归迭代：异常意图在层间传播中被放大
  │
  ▼
阶段3: 符号映射
  ├── 洛书映射器 (luoshu_mapper.encode)
  │     ├── 文本 → 176 维洛书原生空间向量
  │     ├── 位置敏感散列 → Shannon 熵驱动阴阳分叉
  │     ├── 穿透门控 → 投影
  │     └── 计算 attack_distance / safe_distance
  └── 自组织映射器 (ancient_mapper.map)
        ├── 竞争学习映射
        ├── 频率锁定因子（频繁→低学习率，罕见→高学习率）
        └── LRU 历史缓存保证一致性
  │
  ▼
阶段4: 时序一致性校验 (timing_checker.check)
  ├── 马氏距离 + 窗口异常剔除
  ├── 自适应阈值（EWMA + 硬下限）
  ├── 降级为告警（不拒绝）
  └── intent_drift 信号影响后续轮次信任度
  │
  ▼
阶段5: 敏感信息泄露检测 (sensitive_leak.check)
  ├── 12 类内置正则（phone/idcard/email/bankcard/passport/AWS/GCP/JWT/Bearer/hex_aes）
  ├── Luhn 校验（银行卡）/ ISO 7064 MOD 11-2（身份证）
  └── 处置：high 拦截 / medium 打码 / low 告警
  │
  ▼
阶段6: 外部注入检测 (external_injection.check)
  └── 处置：block 拦截 / warn sanitize
  │
  ▼
阶段7: 提示词泄露检测 (prompt_leak.check)
  └── 处置：block 拦截 / warn 标注
  │
  ▼
返回 ProtectResult
  ├── allowed: bool
  ├── reject_stage: str (拒绝发生阶段)
  ├── trust_level: HIGH/MEDIUM/LOW/UNKNOWN
  ├── domain_distance: float
  ├── timing_distance: float
  ├── trust_decay_value: float
  └── intent_drift_detected: bool
```

### 4.4 各模块详解

#### 4.4.1 内生域感知（Reject Gate — 外门）

**文件**: [src/daoti_xuandun/reject_gate.py](file:///h:/XuanDun/src/daoti_xuandun/reject_gate.py)

**职责**: 在线原型距离比较，自主识别未知域。不依赖静态域分类器。

**三阶段决策模型**:

| 阶段 | 条件 | 处置 |
|------|------|------|
| 域内 | 距离近，信任等级 HIGH/MEDIUM | 直接通过 |
| 域外良性 | 距离远但结构正常，信任等级 LOW | 进入混沌期孵化 |
| 攻击 | 距离远且结构异常 | REJECT |

**双信号融合**:
1. **原型距离**（域熟悉度）: 输入与已知安全域的余弦距离
2. **结构异常**（可疑度）: 字节流/字符分布的统计偏差

**活性防护特性**:
- 重复输入自动降低距离（重复缓存机制）
- 模式遗忘基于单调时钟 + 老化分数（频率×新鲜度）
- 5 维攻击否定信号 → EWMA 动态权重学习
- 冷启动自动预热 + 内置攻击原型库

**内置攻击原型**: 覆盖直接提示注入、越狱攻击（DAN）、编码混淆（Base64/Hex/Leet）、数据泄露、工具调用/Agent 攻击、社会工程/权限提升等类别。

#### 4.4.2 攻击模式匹配规则库

**文件**: [src/daoti_xuandun/preprocessors.py](file:///h:/XuanDun/src/daoti_xuandun/preprocessors.py)

**职责**: 所有攻击检测的规则匹配核心，覆盖中英文、编码混淆、Unicode 混淆等多维度攻击识别。

**检测函数**:

| 函数 | 检测目标 |
|------|---------|
| `contains_attack_keywords()` | 通用攻击关键词 |
| `contains_strong_attack_keywords()` | 强攻击关键词 |
| `detect_roleplay_pattern()` | 角色扮演越狱（触发词+指示词+同义词扩展） |
| `detect_social_engineering()` | 社会工程攻击 |
| `detect_data_exfiltration()` | 数据泄露 |
| `detect_system_prompt_leak()` | 系统提示词泄露 |
| `detect_excessive_agency()` | 过度代理 |
| `detect_dangerous_command_pattern()` | 危险命令（rm -rf / DROP TABLE 等） |
| `detect_training_data_exploitation()` | 训练数据利用 |
| `detect_leet_speak_attack()` | Leet speak 编码攻击 |
| `detect_chinese_harmful_content()` | 中文公序良俗/学术包装/越狱 |
| `try_decode_payloads()` | Base64/Hex 解码 |
| `normalize_unicode()` | NFKC 归一化 + 零宽字符移除 |
| `check_imperative_whitelist()` | 命令式良性白名单（防误报） |

**数据结构**:
- `_ATTACK_KEYWORDS` / `_STRONG_ATTACK_KEYWORDS`: 攻击关键词分级表
- `_SYNONYM_EXPANSION`: 同义词扩展表
- `_IMPERATIVE_BENIGN_PHRASES`: 命令式良性短语白名单

#### 4.4.3 洛书符号映射器

**文件**: [src/daoti_xuandun/luoshu_mapper.py](file:///h:/XuanDun/src/daoti_xuandun/luoshu_mapper.py)

**职责**: 语言无关的符号级安全域表征核心。将文本编码到 176 维"洛书原生空间"，基于 64 卦原型计算攻击/安全距离。

**编码流程**:
```
文本 → 位置敏感散列 → Shannon 熵驱动阴阳分叉 → 穿透门控 → 投影 → 176维向量
```

**三阶段自适应学习**:

| 阶段 | 名称 | 说明 |
|------|------|------|
| Phase A | 出厂原型 | 内置安全/攻击原型，冷启动即用 |
| Phase B | 影子缓冲 | 领域偏移检测，积累新原型 |
| Phase C | 稳态微调 | 抗毒化三道门保护下的增量学习 |

**抗毒化三道门**（Phase C 学习保护）:

| 门 | 条件 | 目的 |
|----|------|------|
| Gate A | 攻击相似度检查 | 防止攻击样本被学习为安全原型 |
| Gate B | 窗口速率限制 | 防止短时间内大量样本毒化 |
| Gate C | 总量上限 500 | 防止原型库无限膨胀 |

**关键参数**:
- `LUOSHU_NATIVE_DIM = 176`: 洛书空间原生维度
- `GUA_NAMES`: 64 卦名称列表
- 安全原型加载: 多候选路径解析（源码/打包/工作目录）

#### 4.4.4 动态阴阳壳

**文件**: [src/daoti_xuandun/dynamic_shell.py](file:///h:/XuanDun/src/daoti_xuandun/dynamic_shell.py)

**职责**: 防御层单向不可逆变换，通过混沌动力学将输入文本变换为难以逆向工程的中间表征。

**核心机制**:

| 机制 | 说明 |
|------|------|
| 混沌序列 | logistic map 生成非零偏置 |
| 密钥派生 | 密钥 + 调用计数 + 会话种子 → 混沌偏置 |
| 周期扰动 | 每 N 次调用注入随机扰动防拟合 |
| 强制重组 | 会话查询超限时重组权重 |
| 权重演化 | 状态依赖的外积更新 |
| byte_anomaly 注入 | 变换中注入字节异常信号 |

#### 4.4.5 Rust 双梯形镜像递归网络

**文件**: [crates/daoti_xuandun_pyo3/src/lib.rs](file:///h:/XuanDun/crates/daoti_xuandun_pyo3/src/lib.rs)

**职责**: 玄盾灵魂级底层算法。将静态向量映射升级为动态流形演化，通过 PyO3 暴露为 Python 可调用模块。

**核心思想**:
```
输入文本 → 多层双向递归迭代 → 形成"动态轨迹"
  正向传播（底层→顶层）：捕捉结构依赖和指令嵌套
  逆向传播（顶层→底层）：回溯语义，发现隐藏的意图偏移
  递归迭代：异常意图在层间传播中被放大
```

**状态更新公式**:
```
h_f_new = tanh(W_f · h_f_prev + U_f · h_b_curr + b_f)
h_b_new = tanh(W_b · h_b_next + U_b · h_f_curr + b_b)
```

**关键方法**:

| 方法 | 用途 |
|------|------|
| `forward()` | 前向传播，返回轨迹特征 |
| `analyze_and_adjust()` | 合并 analyze + get_adjustment 为单次 forward，返回四元组 |

**返回值**: `(anomaly_boost, confidence_reduction, debug_info, analyze_dict)`

**决策逻辑**（由 `attack_signal` 主驱动）:

| 分支 | 条件 | 输出 |
|------|------|------|
| strong_attack_signal | attack_signal ≥ 0.5 | anomaly_boost = 0.4~0.5 |
| moderate_attack_signal | attack_signal ≥ 0.2 | anomaly_boost = 0.2~0.4 |
| high_oscillation_low_signal | attack_signal = 0 | 轻微提升 ~0.1 |

**依赖**: pyo3 0.23 (extension-module), ndarray 0.16, rand 0.8
